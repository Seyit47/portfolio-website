## Context

Front-end challenge with a fixed backend. The interesting part was keeping the editor
predictable while the API could fail or be slow.

## What I built

The `apps/web` workspace: canvas, space switcher, persistence and the `api/` layer with
`http.ts` and `errors.ts`.

## Decisions

- One request pipeline so every call gets the same preparation, parsing and error shape.
- Persist to the URL first (shareable), local storage second (convenient).

## Result

A canvas that survives reloads and API hiccups, with the reasoning written down.
