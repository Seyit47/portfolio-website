## Context

A year-long engagement with a Dubai health-tech company building an AI personal trainer.

## What I built

The data dashboard: server-rendered pages, a component kit for tables, cards and charts, and
the backend logic that feeds them, all inside one Next.js application.

## Decisions

- Server Components for the first paint, client components only where interaction needs them.
- Backend responses shaped per view so the client never over-fetches.
- Preview deployments as the review mechanism, which removed the "works on my machine" step.

## Result

A fast, maintainable dashboard with a review loop that fits a small team. The code belongs to
the company, so there is no public repository to link.
