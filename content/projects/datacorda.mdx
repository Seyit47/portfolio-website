## Context

Datacorda is a US analytics startup. I joined as a frontend developer for a five-month
engagement to build out the customer dashboard and the public site.

## What I built

- A Nuxt 3 dashboard with Vue 3 components, Tailwind, ESLint, Prettier, Husky and commitlint.
- A Nuxt 3 marketing website sharing the same tooling and design tokens.
- Media upload to S3, CI/CD and hosting on Amplify, DNS on GCP.

## Decisions

- Nuxt 3 with SSR for both apps so the website is crawlable and the dashboard loads fast.
- Typed Axios modules per backend service rather than ad-hoc fetch calls.
- Environment parity between dev and prod so a passing preview means a passing release.

## Result

The team could ship dashboard and website changes independently, with previews before
production, which cut delivery time by roughly a third.
