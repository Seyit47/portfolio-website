## Context

Belli Creative is an Ashgabat agency. Over two and a half years I moved its recurring
deliverables from bespoke builds to reusable tools.

## What I built

- A Nuxt 3 CV maker where every form field re-renders the document live, with PDF export.
- A badge generator that lets event organisers design and download SVG or PNG name badges.
- Landing templates for startups that are configured, not coded, and need no CMS.

## Decisions

- Nuxt 3 with SSR and SEO in mind for the public-facing templates.
- Composition API and Pinia for the Vue 3 migration so new tools and old apps share patterns.

## Result

Faster client delivery and a 40% reduction in time to interactive. The source code belongs to the
agency, so there is no public repository to link.
