## Context

GREEN-API exposes the MAX messenger over HTTP. The question was whether a complete client
could live entirely in the browser.

## What I built

Sign-in with `idInstance`, `apiTokenInstance` and `apiUrl`, a conversation view, message
sending, and notification polling, built with React 19, Vite and `@maxhub/max-ui`.

## Decisions

- Direct browser-to-API calls keep the deployment to a static host.
- The official UI kit avoids re-creating messenger components.

## Result

A static site on Vercel that acts as a working MAX chat client.
