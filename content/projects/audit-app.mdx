## Context

Field agents visit dozens of shops a day. Managers had no reliable evidence that visits
happened, and reporting was assembled by hand from chat messages. The brief was a system that
makes each visit verifiable and gives admins a live picture without extra process.

## What I built

- **API** (`apps/api`): Fastify in TypeScript with Prisma on PostgreSQL, JWT auth, S3-compatible
  photo storage and typed route contracts.
- **Admin web** (`apps/admin-web`): Next.js App Router with a live agent map, shop, agent and
  product management, photo review and report export.
- **Mobile** (`apps/mobile`): Flutter app with agent and admin roles, daily routes and a
  GPS-checked camera flow.

## Decisions

- One Figma file is the only design source; anything it does not define follows a written gap
  protocol: detect, propose options, product owner decides, record.
- Specification-driven development: a constitution, then spec, plan and tasks per feature, so
  reviews check compliance instead of taste.
- Docker compose for PostgreSQL and SeaweedFS so local development matches production storage.

## Result

A complete, verifiable audit trail per visit and a live operational view for managers, built
by one developer across three apps.
