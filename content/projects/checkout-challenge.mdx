## Context

A take-home assignment with a fixed backend and explicit evaluation criteria.

## What I built

The `@checkout/web` workspace: catalogue, cart and checkout with TanStack Query for server
state and React Router for navigation.

## Decisions

- Keep the backend untouched and document every integration choice in `docs/INTEGRATION.md`.
- Validate on the client for feedback and trust the API's responses for truth.

## Result

A checkout that meets the published criteria and explains itself.
